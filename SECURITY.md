# Security Policy

## Supported Versions

We currently support and patch vulnerabilities in the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.0   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do **not** report it via a public issue tracker. Instead, report it responsibly by opening a security advisory or contacting the core maintainers directly at `security@framesense.org` (placeholder).

Please include the following information in your report:
* Type of issue (e.g., buffer overflow, SQL injection, RCE)
* Paths or modules affected
* Step-by-step instructions to reproduce the vulnerability
* Any potential mitigation steps

We will acknowledge receipt of your report within 48 hours and work with you to release a patch or security advisory.
